🏯 Maze Sensei Race

🧠 Trains: Reinforcement learning

Race the 🤖 to the 🏆! Before each race, the robot practices the maze using reinforcement learning: more practice runs every level. Move with the arrow buttons or arrow keys. Beat the robot 5 times to win. Lose a race and you lose a life.

Score 0Level 1
How it connects to AI: The robot uses Q-learning: it tries moves, gets a small penalty for every step and a big reward at the trophy, and slowly learns which move is best from each square. With a few practice runs it wanders. With hundreds, it finds the shortest path. Reinforcement learning like this, plus huge amounts of practice, helped AIs master games like Go.
